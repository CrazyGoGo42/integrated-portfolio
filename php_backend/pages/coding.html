02

FRONTEND

Design UI & UX

Das Frontend, was der Benutzer sieht und womit er interagiert, der Inhalt einer Website/App... erscheint hier! Zu studieren, welche Elemente erstellt und wo sie positioniert werden sollen, ist ein entscheidender Teil der Entwicklung, da der Benutzer je nach seinen Bedürfnissen auf die bestmögliche Weise durch die Navigation geführt werden muss. Es muss sich an verschiedene Geräte anpassen können, ohne natürlich auf den visuellen Eindruck zu verzichten!

03

BACKEND

Das Herz einer App

Wenn das Frontend das äußere Erscheinungsbild einer Website ist, ist das Backend ihr verborgener Motor. Hinter den Kulissen ermöglicht es die Verbindung zur Datenbank, das Hinzufügen von Funktionalitäten, die Verwaltung von Inhalten und vieles mehr. Beide müssen in perfekter Synergie arbeiten für ein optimales Ergebnis.

CMS

Content Management Systems sind Webanwendungen, die eine Schnittstelle zum Backend ermöglichen. Es sollte dasjenige gewählt werden, das am besten geeignet ist, die spezifischen Funktionalitäten der Website zu unterstützen. In meinen Jahren als Entwickler habe ich mein eigenes CMS, Minerva, erstellt, um meinen Websites ein Herz zu geben, das überall ohne zusätzliche Kosten funktionieren kann.
